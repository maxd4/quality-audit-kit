# Licensing and reuse policy

**Decision for this documentation-first repository:** Apache-2.0 for original materials only.

CleanMyMap's existing code is separately published under `AGPL-3.0-only`. This repo's `LICENSE` neither overrides that license nor grants rights over third-party scanner implementations or assets.

| Approach | Suitable licensing path | Constraint |
| --- | --- | --- |
| Brand-new independent engine-neutral code | Apache-2.0 (proposed) | Confirm authorship and that no copyleft portions were copied |
| Direct extraction of existing CleanMyMap implementation | Preserve AGPL obligations by default | Audit rights, authorship, contributions and derivative status before any relicensing |
| Third-party scanner/adapters | Inspect each upstream license | Adapter can invoke tools without redistributing bundled binaries by default |

Do not automatically transfer the project trademark, CleanMyMap screenshots, personal data, baselines, source files or proprietary evidence to this repository. Independently verify intellectual-property ownership before relicensing anything copied.

This is project guidance, **not a legal determination**. If material licensing ambiguity remains, keep it out of the publication until reviewed.
